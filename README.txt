LOT DRAWER — Chrome Package

1. Extract this ZIP.
2. Open index.html in Google Chrome.
3. All image assets are included in the assets folder.
4. Sound effects use the browser's built-in Web Audio API; no external audio files are required.

Internet is not required for the app itself, except the Barlow Condensed web font may load from Google Fonts if available. The app will still work if the font cannot be loaded.
